# 万方科研诚信培训系统刷课脚本

[简体中文](README.md) | [English](README.en.md)

用于万方科研诚信培训系统的 Tampermonkey 用户脚本，提供视频播放辅助、章节切换、服务端学习记录核对、测验处理与诊断导出。

**当前版本：v1.6.0** · [脚本源码](src/wf-auto-course.user.js) · [反馈问题](https://github.com/XiaobaiBye/wanfang-integrity-training/issues)

## 适用范围

适配已登录的万方科研诚信培训课程学习页和考试页：

```text
https://cx.wanfangdata.com.cn/e-training/quality/courselearn?courseId=...
https://cx.wanfangdata.com.cn/e-training/lecture/courselearn?courseId=...
https://cx.wanfangdata.com.cn/e-training/exam/examboard
```

脚本依赖页面当前的 Vue/Vuex 结构和接口，平台更新可能影响兼容性。无需构建项目或启动服务，安装用户脚本即可运行；英文文档不改变脚本的中文界面。

## 主要功能

| 功能 | 当前行为 |
| --- | --- |
| 播放辅助 | 默认静音、1x 播放，提供开始、暂停和卡顿恢复 |
| 倍速控制 | 支持面板循环切换 1 / 1.25 / 1.5 / 1.75 / 2x，显示实际倍速并纠正重置 |
| 章节切换 | 略过已完成节点，通过页面原目录点击进入下一节；定位不唯一或切换超时则暂停 |
| 学习记录核对 | 对比本地时长与服务端课程树，显示服务端是否确认完成 |
| 补时播放 | 服务端未确认且存在时长缺口时，尝试从头以 1x 重播；无有效增长或核对失败时暂停 |
| 随堂测验 | 支持自动探测、纠正提交，以及人工处理模式 |
| 考试 | 支持考试列表页选择试卷、开始、填写可用答案、导入答案和独立提交；课程关联自动考试默认关闭 |
| AI 解题 | 使用你配置的 OpenAI 兼容接口分批生成建议和简短理由；检查后单独填入，交卷仍独立操作 |
| 排障工具 | 导出诊断包、文本日志和摘要，提供控制台调试接口 |

视频进度、本地累计时长、上报请求成功，都不能单独证明服务端已保存或认定课程完成。默认以服务端完成状态为准。倍速也不保证缩短平台要求的真实学习时间。

## 安装与更新

1. 在 Chrome 或 Edge 中安装并启用 **Tampermonkey**，按扩展提示允许用户脚本运行。
2. 打开 [脚本安装链接](https://raw.githubusercontent.com/XiaobaiBye/wanfang-integrity-training/main/src/wf-auto-course.user.js)。如果出现 Tampermonkey 安装页，点击安装。
3. 如果浏览器只显示源码，在 Tampermonkey 中新建脚本，清空模板，粘贴完整源码并保存。
4. 登录万方培训系统，打开课程学习页或考试页。右上角出现 v1.6.0 面板后即可使用。

更新时，用最新源码完整替换已安装的脚本并保存，再刷新课程页。当前脚本未配置 `@updateURL` / `@downloadURL`，请手动检查版本并更新，避免同时启用多份脚本。

v1.6.0 新增 Tampermonkey 跨域请求、脚本存储与页面上下文权限。更新时按扩展提示允许权限。`@connect *` 用于支持用户自定义接口域名；AI 请求只在点击「AI 解题」后发往已配置地址。

## 使用方法

### 考试页面

打开 [考试列表页](https://cx.wanfangdata.com.cn/e-training/exam/examboard)，右上角会出现独立的考试助手。

1. 选择试卷，点击「开始所选考试」。助手使用网页原有的考前须知与开始流程；页面倒计时随之开始，到期仍会按页面规则自动交卷。
2. 点击「填写可用答案」，仅填写当前试卷实际提供 `rightAnswer` 的题目。缺少答案的题目保留人工选择，不会提交探测卷或猜答案。
3. 可点击「导出题目」，或粘贴题目 ID 到原始选项字母的 JSON，点击「导入并填写」，例如 `{"3260":"A,C","3261":"B"}`。字母对应原始选项，助手按本次试卷的随机顺序转换到显示选项；支持单选、多选和判断题。
4. 检查页面选中状态后，点击「提交已填写试卷」。缺题、映射异常或正在提交时会阻止本助手交卷。页面原有的手动作答和交卷仍可使用。

本助手不在进入考试页时自动开始或交卷，不保证题目接口提供答案。首次适配基于公开前端模块和模拟测试，实际账号的题目字段、权限和交卷结果仍需在线验证。出现异常时，先导出诊断包；其中包含试卷、选项和答案，请留意分享范围。

控制台接口：`__CX.examBoard.inspect()`、`.start(examId)`、`.fill()`、`.fill({题目ID: 'A,C'})`、`.submit()`。`start` 会开始计时，`submit` 会实际交卷。

### AI 解题

1. 在考试助手展开「AI 解题设置」，填写兼容 Chat Completions 的接口地址、模型名称及 API Key。地址可为 `https://服务商/v1` 或完整的 `.../chat/completions`；不默认选择模型，使用服务商实际支持的名称。
2. 点击「保存 AI 配置」。密钥默认只保存在当前脚本会话，刷新后需重新输入；勾选「记住密钥」才写入 Tampermonkey 存储。密钥不写入站点 localStorage、配置导出或诊断包，可点击「清除密钥」删除。
3. 开始试卷后，可先「填写可用答案」，再点击「AI 解题」。只发送缺少平台答案且尚未作答的题目 ID、题型、题干和选项，不发送登录 Cookie 或整份诊断包。服务商可能计费；每批最多 5 题，顺序请求，失败不自动重试，90 秒超时，可随时停止。
4. 检查预览中的页面选项及理由，再点击「填入 AI 建议」。不会覆盖已经作答的题目；切换试卷或选项顺序变化后，旧建议失效。未知题号、重复题号、无效选项及模型未确定的答案不会直接填入。
5. 仍需检查整张试卷，再单独提交。AI 答案可能错误；模型不确定或返回格式异常时，题目保留人工处理。页面原有考试倒计时和到期自动交卷规则不变。

若接口支持，可勾选「启用 JSON 模式」，发送 `response_format: {type: 'json_object'}`；不支持时保持关闭，脚本仍要求并校验 JSON 内容。协议按 [OpenAI Chat Completions 文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)实现，兼容服务的具体模型与字段支持需实际验证。

控制台接口：`__CX.ai.config()`（不返回密钥）、`.configure({endpoint, model, apiKey, rememberKey: false, jsonMode: false})`、`.solve()`、`.cancel()`、`.apply()`、`.clearKey()`。请在面板中输入密钥，不要将真实密钥粘贴到问题反馈或诊断说明中。

### 课程页面

打开课程页后，脚本默认自动运行。首次使用可先点击「暂停」，在页面原目录中选择需要学习的章节，再点击「开始」。

| 面板内容 | 说明 |
| --- | --- |
| 开始 / 暂停 | 控制助手运行；暂停会废弃当前异步播放处理任务 |
| 下一节 | 手动请求进入下一未完成节点，不代表当前节已经完成 |
| 倍速按钮 | 循环选择目标倍速；补时期间强制使用 1x |
| 考试 | 尝试读取并提交当前课程关联考试；点击可能实际交卷 |
| 本地 / 服务端 / 差 | 本地累计时长、已读取的服务端时长、补时缺口 |
| 服务端状态 | 已完成、未认可、无记录或未核对 |
| 上报 X/Y | 观察到的 `insertrecord` 成功响应次数 / 请求次数，不等同于保存成功次数 |
| 诊断包 / 导出日志 / 复制摘要 | 下载或复制当前排障信息 |

正常播放等待视频自然结束，再等待结算并核对。开启自动下一节时，如果对账提前确认服务端已完成，也会直接切节。默认不会仅凭本地进度走完而放行；补时也不会在面板显示的缺口倒计时结束时直接认定完成。

## 配置

在课程页打开浏览器开发者工具的 Console，读取或修改 `__CX.cfg`，调用 `__CX.save()` 保存。配置存储在当前站点的浏览器 `localStorage`（键名 `cx_cfg_v2`）。

例如，改为人工处理随堂测验：

```js
__CX.pause();
__CX.cfg.quizStrategy = 'manual';
__CX.save();
__CX.resume();
```

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `rate` | `1` | 目标播放倍速，也可通过 `__CX.rate(1.5)` 设置并保存 |
| `rateGuard` | `true` | 守护倍速，并在检测到倍速影响完成时尝试降至 1x |
| `mute` | `true` | 播放时静音 |
| `autoNext` | `true` | 视频完成确认后自动切节 |
| `skipFinished` | `true` | 略过已完成的视频节点 |
| `autoQuiz` | `true` | 自动处理测验节点；关闭后留给人工处理 |
| `quizStrategy` | `'probe'` | 自动探测与纠正；设为 `'manual'` 时暂停等待人工 |
| `autoExam` | `false` | 全部节点处理完后尝试自动考试 |
| `verify` | `true` | 核对服务端记录；建议保留开启 |
| `topUp` | `true` | 未确认完成且有时长缺口时尝试 1x 重播 |
| `settleWait` | `4000` | 视频结束后的结算等待时间，单位毫秒 |
| `selfHeal` | `true` | 启用卡顿检测与恢复尝试 |
| `netLog` | `true` | 记录用于诊断的网络信息 |

默认配置还保留 `completeRatio: 1`、`finishGap: 0`、`strictComplete: true` 和 `verifyMode: 'strict'`。其中部分为历史兼容字段；当前视频核对失败的处理分支会暂停，不应依靠修改这些字段实现宽松放行。

`running` 不持久化，刷新页面会默认重新运行。`__CX.reset()` 可恢复默认配置并保存。

## 已知限制与排障

- **目录切换仍需实测。** v1.4.7 优先点击资源绑定容器内部的文字或带点击事件的入口，已有模拟回归覆盖，但不能据此保证所有实际课程目录均可切换。失败时暂停助手，在原目录手动选择章节后恢复。
- **切节进度异常和 HTTP 500 未在本版修复。** 服务端异常或记录迟迟不增长时，先检查平台原页面及网络，再尝试恢复。
- **自动测验可能实际提交答案。** 默认 `probe` 模式在缺少答案时先提交探测答案，再尝试读取并纠正；若仍未返回答案，可能保留探测结果并继续，不能保证正确率或服务端已完成。需要自行作答时使用 `manual` 模式。
- **考试答案可能缺失。** 考试页仅填入接口已提供或用户导入的答案；缺少题目时需人工处理，不保证考试通过。课程关联考试仍要求接口提供全部答案。
- **后台播放受浏览器影响。** 防后台暂停处理不能消除浏览器节流、系统休眠或网络中断。卡顿时先将课程页切回前台。

提交问题时请附上脚本版本、浏览器版本、操作步骤、预期与实际结果，并按需提供脱敏诊断信息。诊断包可能包含页面地址、课程与资源标识、请求内容、接口响应或题目数据，分享前请检查并脱敏。

## 控制台调试

以下命令在已加载脚本的课程页执行：

```js
__CX.version           // 当前版本
__CX.runtime()         // 任务代数、当前上下文、是否有等待任务
await __CX.check()     // 立即请求一次服务端对账
__CX.server()          // 查看已读取的服务端课程记录
__CX.ledger()          // 查看本地与服务端时长对照
__CX.rateInfo()        // 查看目标倍速、实际倍速与守护记录
await __CX.verify('3.4') // 强制核对指定章节编号
await __CX.refresh()   // 刷新服务端课程树
__CX.diag()            // 下载完整诊断包
__CX.dump()            // 在控制台返回完整诊断对象
__CX.pause()           // 暂停助手
__CX.resume()          // 恢复助手
```

## 开发与验证

```text
.
├── README.md                    # 中文文档
├── README.en.md                 # 英文文档
├── src/
│   └── wf-auto-course.user.js    # 可直接安装的用户脚本
└── tests/
    ├── rate-harness.js          # 倍速、面板与缺口计算回归
    ├── lifecycle-harness.js     # 异步生命周期、切节与完成核对回归
    ├── exam-harness.js          # 考试启动、随机选项、填写与交卷回归
    └── ai-harness.js            # AI 接口、密钥隔离、取消、分批及结果校验
```

安装 Node.js 后，在项目根目录运行，无需安装 npm 依赖：

```bash
node --check src/wf-auto-course.user.js
node tests/rate-harness.js
node tests/lifecycle-harness.js
node tests/exam-harness.js
node tests/ai-harness.js
```

测试使用模拟 DOM、Vue 状态、播放器和网络响应，验证本地控制逻辑。实际页面兼容性、平台记时及最终完成状态需要在线验证。
